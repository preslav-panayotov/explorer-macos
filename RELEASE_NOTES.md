## Explorer 1.0.0

The first public release of **Explorer** — a native macOS file manager that looks and works like Windows 11 File Explorer.

**Highlights**
- Windows 11 layout in light and dark: navigation pane, breadcrumb address bar, command bar, Details list, status bar, Details pane
- Windows 11-style right-click menus for files, folders, multi-selection and empty space (Open with, Compress, Extract, Send to, Create shortcut, Properties, New ▸ …)
- Real Cut & Paste, inline rename, multi-level Undo, drag & drop, ZIP/extract, recursive search, Group by, six view modes, native tabs

Full feature list: [docs/FEATURES.md](docs/FEATURES.md) · Changes: [CHANGELOG.md](CHANGELOG.md)

**Install:** unzip `Explorer-1.0.0-macOS.zip`, move `Explorer.app` to `/Applications`, then right-click → Open the first time (the app is not notarized). Requires macOS 15+.

SHA-256 of the zip is in the attached `.sha256` file.
